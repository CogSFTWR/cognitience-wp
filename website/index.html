Write to USB

  1. Download the ISO, then check the SHA-256 before you flash it.
  2. Use balenaEtcher: pick the ISO, pick an 8 GiB+ USB stick, Flash. Etcher verifies the write.
  3. Boot from that USB. If the machine refuses the disc, turn off Secure Boot for this session.

dd also works, and it will erase the target disk: 

sudo dd if=silicaos-2026.11.13-x86_64.iso of=/dev/sdX bs=4M status=progress conv=fsync

Verify

sha256sum silicaos-2026.11.13-x86_64.iso
shasum -a 256 silicaos-2026.11.13-x86_64.iso
Get-FileHash .\silicaos-2026.11.13-x86_64.iso -Algorithm SHA256

On the live image

TTY1 autologs in as silica / silica on Hyprland. TTY2 is root with an empty password, for archinstall.
