# Example Cognitience WP plugins

| Package | What it shows |
| --- | --- |
| `jsonl-viewer.cogwp` | File opener for `.jsonl` + sidebar preview |
| `ai-draft.cogwp` | Toolbar AI draft stub (`fetch` to your endpoint) |

Install in WP via **Extensions → Install from file**, or drop the `.cogwp` in Documents and hit **Search → Activate**.

Source folders sit next to the archives (`jsonl-viewer/`, `ai-draft/`).
